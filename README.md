> [!summary] mylifeOS · 人生经营系统
> 一套咨询报告风格的 Obsidian 模板：**PARA 组织法 + 周期笔记 + 自动化视图**。
> **不依赖任何专用插件**：mylifeOS 的全部视图都由 Dataview、Templater、Periodic Notes 等开源插件实现。

## 一、结论先行

1. **结构不变**：沿用 PARA（项目 / 领域 / 资源 / 存档）+ 周期笔记（日 / 周 / 月 / 季 / 年）的方法论，原有笔记与标签可无缝迁移。
2. **功能完整**：mylifeOS 提供 13 种代码块视图、项目 / 领域快照、新建 PARA 向导、侧边栏日历与周期导航。
3. **清爽质感**：自带 *Planner Blue* 主题——近白底色，深海蓝 / 钢蓝 / 浅蓝单色系，粗体标题、细线分隔，支持深色模式。

## 二、目录结构

| 文件夹 | 内容 |
| --- | --- |
| `00 信息资源` | 外部资料、文章、链接的收件箱，每周分流 |
| `01 周期笔记` | 日记 / 周记 / 月记 / 季记 / 年记（从 2026 年 9 月开始） |
| `10 项目` | mylifeOS制作 |
| `20 领域` | AI自媒体、知识管理、FDE AI落地 |
| `30 资源` | 佛学哲学、学习书籍、音乐资源、其他爱好 |
| `40 存档` | 完成或不再活跃的项目 |
| `50 输出` | 小红书文案、公众号视频 |
| `90 系统` | 工作台、任务管理、快捷入口，以及模板（`模板/`）与视图脚本（`视图/pos/`） |

**约定**：每个 PARA 条目是一个文件夹，内含一个 `名称.README.md` 索引文件，其 Properties 中的 `tags` 决定它聚合哪些任务、记录和文件。日记里写 `#知识管理/mylifeOS制作`、`#FDE-AI落地`、`#输出/小红书文案` 等标签，内容就会自动出现在对应的 README 里。

## 三、插件清单

| 插件 | 用途 | 状态 |
| --- | --- | --- |
| Dataview | 视图引擎（需开启 JavaScript 查询，已预设） | 保留 |
| Tasks | 任务状态、截止日期、任务看板 | 保留 |
| Templater | 模板、项目 / 领域快照、新建 PARA 向导 | 保留 |
| **Periodic Notes** | 日 / 周 / 月 / 季 / 年笔记的创建与模板 | 新增 |
| **Calendar** | 侧边栏日历，点击日期 / 周数即可创建笔记 | 新增 |
| **Homepage** | 启动时自动打开 `工作台` | 新增 |
| Fuzzy Chinese Pinyin、Copy Block Link、Better Search Views | 拼音搜索、块链接、搜索增强 | 保留 |

## 四、日常使用

**每天**：打开工作台（`Alt + H`）→ 点「开始今天」或 `Alt + D` 打开今日笔记 → 写下 Top 3 → 在「项目列表」里的项目后面记录耗时（`2hr30`、`45min`、`1.5h` 都能识别）→ 在「日常记录」里随手记，用 `#标签` 关联项目。零碎想法可以直接在工作台「快速捕获」里写，会自动追加到今日日记（`Ctrl/⌘ + Enter` 记录，`Ctrl/⌘ + Shift + Enter` 记为待办）。

**每周 / 月 / 季 / 年**：打开对应周期笔记，视图会自动汇总这段时间的项目耗时、收集的任务与闪念、完成的任务；再在「复盘」里写核心结论和 Continue / Start / Stop。

**新建项目**：`Alt + N` → 选择类型 → 输入标签（如 `AI自媒体/十月选题`）→ 自动生成 `10 项目/AI自媒体-十月选题/十月选题.README.md`。

**每周**：打开周记（工作台「本周」），在「领域计划」写任务，周末看看板和精力分配，写「核心结论」。

**归档项目**：把项目文件夹拖进 `40 存档`，它会自动出现在所属领域 README 的「归档」列表里。

## 五、写作组件

主题为咨询式写作提供了几个 Callout：

> [!takeaway] 核心结论
> `> [!takeaway]`：Key takeaway，放最重要的判断。

> [!sowhat] So what?
> `> [!sowhat]`：追问这件事意味着什么。

> [!exhibit] 图表 1
> `> [!exhibit]`：图表或数据说明。

> [!risk] 风险
> `> [!risk]`：风险与假设。

`> [!grid]` 会把其中的多个块排成两栏。

## 六、工作台

| 区域 | 内容 |
| --- | --- |
| 标题 + 日期框 | 大字「人生经营 · 工作台」、日 / 周 / 月 / 季 / 年按钮；右上角日期框（点击打开今日日记） |
| 指标条 | 今日完成、本周完成率、今日专注（项目耗时）、习惯打卡、已逾期 |
| 任务优先矩阵 | 按「重要 × 紧急」把未完成任务分进四象限（重要 = `[!]` `[/]` 或关联领域 / 项目标签；紧急 = 2 天内到期） |
| 今日清单 | 今天到期 / 今日日记里的任务，可勾选；输入框回车直接写入今日日记 |
| 日程与时间线 | 今日日记『日常记录』里带 `HH:mm` 的记录按小时排开 |
| 番茄钟 | 25 分钟专注 / 5 分钟短休 / 每 4 个番茄 15 分钟长休 |
| 本周目标 | 周记里的一句话目标 + 『领域计划』前 4 项 |
| 习惯追踪 | 本周每天日记『习惯打卡』的完成情况 |
| 本周灵感 | 本周日记里的最新想法 |
| 效率分析 | 本周任务概况、每日专注时长、近 8 周完成率趋势、本周任务领域分布 |
| 本周任务看板 | 逾期遗留 / 待办 / 进行中 / 已完成，可直接勾选 |
| 底部 | 在管项目、责任领域、最近更新、每日提醒 |

**左侧栏「快捷入口」**：工作台（打开 Homepage 主页）、任务管理、本周复盘。

工作台页面会自动隐藏标题、笔记属性和文末的「链接当前文件 / 提到当前文件名」；其他笔记不受影响（反向链接仍可在右侧栏查看）。

## 七、周记 × 任务

- **周记就是任务看板**：周记顶部是「本周任务看板」，自动汇总四类任务——周记「领域计划」里写的、本周日记里收集的、本周到期的、本周完成的；当周还会显示之前逾期未完成的「遗留」。
- **计划写在周记里**：按 AI自媒体 / 知识管理 / FDE AI落地 / 生活与自己 四栏写任务，带上日期 `📅 2026-10-03` 就会进入对应的列。
- **任务管理看趋势**：本周看板 + 最近 8 周的完成率（每周链接到当周周记）+ 按领域 / 未排期 / 已取消的全局视图。
- **状态约定**：`[ ]` 待办　`[/]` 进行中　`[!]` 重要　`[>]` 延期　`[-]` 取消　`[x]` 完成。

## 八、自定义

- **改文件夹名或标题**：编辑 `90 系统/视图/pos/view.js` 顶部的 `CFG`，并同步修改 Periodic Notes / Templater 设置中的路径。
- **改配色**：编辑 `.obsidian/themes/Planner Blue/theme.css` 顶部的色板变量；工作台组件色板在 `90 系统/视图/pos/view.css`。
- **项目状态**：默认根据截止日期自动判断（进行中 / 临近截止 / 已逾期 / 已完成）；也可在 README 的 Properties 中手动写 `status: 暂停`。

## 九、首次打开

1. 用 Obsidian「打开文件夹作为仓库」选择本文件夹。
2. 弹出「是否信任作者并启用插件」时选择**信任**（插件已随仓库附带，无需联网下载）。
3. 工作台会自动打开；若没有，按 `Alt + H`，或点左侧栏「快捷入口 → 工作台」。
4. 日历在左侧栏顶部；若被关掉了，用命令面板运行「Calendar: Open view」。
