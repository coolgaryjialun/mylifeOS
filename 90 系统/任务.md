> [!summary] 任务总览 · 以周为单位推进
> 周记就是任务看板：在周记『领域计划』里写本周要做的事，日记里随手收集的待办、本周到期和本周完成的任务，都会自动汇总到这里。
> 状态约定：`[ ]` 待办　`[/]` 进行中　`[!]` 重要　`[>]` 延期　`[-]` 取消　`[x]` 完成

## 值得关注
> 重要 / 进行中 / 高优先级 / 7 天内到期

```tasks
not done
(status.name includes Important) OR (status.name includes In Progress) OR (priority is high) OR (due before in 7 days)
sort by due
```

## 按领域
```tasks
not done
group by tags
```

## 未排期
> 没有截止日期的待办，每周复盘时挑出来排进下周

```tasks
not done
no due date
no scheduled date
(folder includes 01 周期笔记) OR (folder includes 10 项目) OR (folder includes 00 信息资源)
group by folder
```

## 已取消
```tasks
status.name includes Cancelled
group by folder
```
